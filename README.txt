# FitMotion 3D

Mobile-first fitness website with:
- Home / Waist / Abs liquid-style navigation
- Interactive Three.js 3D mannequin
- Drag to rotate
- Mouse-wheel/pinch-style browser zoom via wheel
- Play/Pause, Reset, Reverse and speed control
- All requested Waist and Abs exercises
- Exercise instructions, focus and form warnings

## Files
- index.html
- style.css
- script.js

## Run
Because `script.js` imports Three.js from jsDelivr, the browser needs internet access.

Easiest:
1. Put all 3 files in the same folder.
2. Open `index.html` in a browser, or use Replit / GitHub Pages / Netlify.
3. On a phone, landscape mode gives the 3D viewer more room.

The 3D trainer is a procedural interactive mannequin rather than a photorealistic motion-capture human. The animation is generated in JavaScript for each exercise.
